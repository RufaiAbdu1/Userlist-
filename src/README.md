# UserList App

Wannan React + Vite app yana yin fetching daga external API (`jsonplaceholder.typicode.com/users`) sannan ya nuna jerin users. Ana amfani da reusable `ListComponent` wanda ke karɓar props (`items` da `renderItem`) don nunawa.

## Features

- API Integration (Fetch users)
- Loading and error state management
- Reusable ListComponent with props
- Vite + React

## Start

```bash
npm install
npm run dev
